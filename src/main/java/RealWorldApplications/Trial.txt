Project Name: 4680-68-Overdraft Delinquency Counter Reset

Project Description:

The primary objective of this project is to ensure compliance with policy and regulatory requirements by enhancing the accuracy of the delinquency counter logic in the CACS system for overdraft accounts.

The updated logic will accurately track the number of consecutive days an account remains more than its Authorized Overdraft Limit (AOL), addressing gaps in the current process and ensuring proper classification of accounts that exceed the 90-day delinquency threshold. This includes replacing the use of the Last Deposit Date with a more reliable calculation based on the Overdraft Start Counter (O/D START CNTR) and Excess Counter (EXCESS CNTR).
